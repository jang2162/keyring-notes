# 배포 전 확인

## 릴리스나 공개 전에 README 와 사용자 문서를 아래 목록으로 모두 확인한다

- [ ] 한 줄 설명이 저장소 About 설명과 같다
- [ ] 대표 이미지나 데모 GIF 가 최신 UI 와 맞는다
- [ ] 모든 이미지에 alt 가 있고, 개인 정보·API 키가 보이지 않는다
- [ ] 설치 명령을 깨끗한 환경에서 그대로 복사해 실행해 성공했다
- [ ] 빠른 시작 예제의 출력이 실제 결과와 같다
- [ ] 배지가 모두 정상으로 보인다
- [ ] 모든 링크(내부 문서, 외부 사이트, 후원 페이지)가 열린다
- [ ] 요구 사항의 버전 정보가 지금 지원 범위와 맞다
- [ ] `CHANGELOG.md` 에 이번 버전의 변경 사항이 있다
- [ ] 영어 원본의 변경이 번역본에도 들어갔다(못 했다면 `translation` 이슈와 맨 위 알림이 있다)
- [ ] 모든 README 의 언어 전환 줄이 서로 맞게 이어진다
- [ ] 빈 섹션, `TODO`, 「작성 예정」 문구가 없다
- [ ] GitHub 화면에서 라이트·다크 모드 모두 확인했다

- **Why:** 위 항목은 저장소 안에서는 멀쩡해 보이고 GitHub 첫 화면이나 처음 쓰는 사람의 환경에서만 드러난다.
- **How to apply:** 확인하지 못한 항목은 공개 전에 남은 일로 보고한다. 확인한 것처럼 체크하지 않는다.
