# 다국어 문서

## 영어가 원본이고, 번역본은 원본과 파일 이름·구조·섹션 순서가 같다

| 언어 | README | 사용자 문서 | 역할 |
| --- | --- | --- | --- |
| English | `README.md` | `docs/manual/en/` | 원본 |
| 한국어 | `README.ko.md` | `docs/manual/ko/` | 번역본 |
| (추가 언어) | `README.<lang>.md` | `docs/manual/<lang>/` | 필요할 때 추가 |

- 언어 코드는 ISO 639-1 소문자를 쓰고, 지역 구분이 필요할 때만 붙인다(`ja`, `zh-CN`, `pt-BR`).
- `CHANGELOG.md`, `CONTRIBUTING.md`, `LICENSE` 는 영어로만 둔다.
- `docs/manual/README.md` 는 언어 선택 페이지로 두고, 각 언어 폴더의 시작 문서로 잇는다.

- **Why:** 구조가 같아야 상대 링크가 언어 폴더만 바꿔 그대로 동작하고, 언어를 더할 때 폴더를 복제하기만 하면 된다.
- **How to apply:** 번역본에서 파일을 더하거나 이름을 바꾸지 않는다. 원본에서 바꾸고 번역본을 따라 바꾼다.

## 모든 README 맨 위(로고 위)에 언어 전환 줄을 둔다

현재 언어는 굵게, 나머지는 링크로 쓴다.

- `README.md`: `**English** | [한국어](README.ko.md)`
- `README.ko.md`: `[English](README.md) | **한국어**`

- **Why:** 원본이 영어라, 전환 줄이 없으면 번역본이 있어도 첫 화면에서 찾지 못한다.
- **How to apply:** 언어를 더하면 모든 README 의 전환 줄과 `docs/manual/README.md` 에 함께 넣는다.

## 원본을 바꾸면 같은 PR 에서 번역본도 고치고, 못 하면 뒤처졌다고 표시한다

- 영어 원본을 바꾸는 PR 에서 번역본도 함께 고친다. 바로 못 하면 `translation` 라벨로 이슈를 만든다.
- 번역본 맨 위에 기준이 된 원본 버전을 주석으로 남긴다 — `<!-- source: README.md @ v1.2.0 -->`.
- 번역이 원본보다 뒤처져 있으면 맨 위에 알림을 둔다 — `> [!NOTE]` 이 문서는 v1.2.0 기준이며 최신 내용은 영어 문서를 확인하세요.

- **Why:** 표시 없이 뒤처진 번역본은 옛 절차를 최신인 것처럼 보인다.
- **How to apply:** 원본을 고친 PR 을 올리기 전에 같은 경로의 번역본이 있는지 본다.

## 새 언어는 원본을 복제해 더한다

1. `README.md` 를 복사해 `README.<lang>.md` 를 만들고 번역한다.
2. `docs/manual/en/` 을 통째로 복사해 `docs/manual/<lang>/` 을 만들고 번역한다.
3. 모든 README 의 언어 전환 줄과 `docs/manual/README.md` 에 새 언어를 더한다.
4. 용어 대응을 `docs/manual/glossary.md` 에 더한다.
