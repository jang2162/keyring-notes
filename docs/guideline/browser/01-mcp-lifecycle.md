# 브라우저 서버가 안 붙을 때

## 도구 목록은 세션이 시작될 때 한 번 찍는 사진이고, 툴 호출은 매번 거는 전화다

**언제 꺼져 있었는가로 고장이 갈린다. 둘은 같은 고장이 아니다.**

| 언제 꺼져 있었나 | 증상 | 회복 |
| --- | --- | --- |
| **세션이 시작될 때** | 그 서버의 툴이 도구 목록에 **하나도 없다** | **사람이 재연결**(`/mcp`)하거나 세션을 새로 연다 |
| **세션 도중에** | 도구는 그대로 있고 **호출만** 연결 실패로 떨어진다 | **앱만 다시 켜면 된다.** 다음 호출이 알아서 붙는다 |

- **Why:** 도구 목록은 세션이 시작될 때 핸드셰이크로 한 번 받아 오고 **그 뒤로 다시 묻지 않는다.** 반면 HTTP 로 붙는 서버는 **툴 호출마다 새로 연결하므로**, 서버가 돌아오면 다음 호출이 그냥 성공한다.
- **How to apply:**
  - **증상으로 먼저 가른다.** 호출이 실패했다고 재연결부터 찾지 않는다 — 앱만 켜면 되는 경우에 **사람을 붙들어 세우게 된다.**
  - 앱을 켜는 것은 에이전트가 해도 된다. **켤 때 화면을 뺏지 않는 옵션을 준다**(`base` 스택 「에이전트 기본」).
  - ⚠ **전송 방식을 바꾸는 것은 답이 아니다.** stdio 로 바꾸면 시작 시점 문제는 사라지지만 **도중에 죽은 서버는 세션이 끝날 때까지 살아나지 않는다** — 죽은 자식 프로세스는 다시 뜨지 않는다. 한쪽을 고치면 다른 쪽을 잃는다. **답은 세션을 열기 전에 켜 두는 것**이고, 로그인 항목에 넣어 두면 두 고장이 **한꺼번에** 사라진다.

## 서버가 살아 있는 것과 이 세션에 툴이 붙어 있는 것은 다르다

세션이 열릴 때 꺼져 있었으면 그 세션에는 그 서버의 툴이 **하나도 없고, 나중에 앱을 켜도 소급되지 않는다.**

- **Why:** CLI 의 서버 목록이 `Connected` 를 보여 줘도 그것은 **지금 서버가 살아 있다**는 뜻이다. 이미 떠 있는 세션의 도구 목록과는 관계가 없다.
- **How to apply:**
  - **확인은 도구 목록에서 그 이름을 직접 찾아 한다.** 「찾지 못했다」가 나오면 이 세션에는 **없는 것**이다.
  - 그때 **「연결 실패한 서버」 목록에도 그 이름이 없다는 것을 같이 본다** — 실패한 것이 아니라 **애초에 목록에 들어오지 않은 것**이고, 그래서 앱을 켜도 달라지지 않는다.
  - 회복은 둘뿐이고 **둘 다 사람이 해야 한다** — 재연결(세션 유지), 또는 세션을 새로 열기.
  - ⚠ **먼저 재연결 목록에 그 이름이 있는지 본다.** 그 목록은 **연결에 실패한 서버도 보여 준다.** 그런데도 이름이 아예 없다면 **서버를 세션이 시작된 뒤에 설정에 추가한 것**이고, 그때는 누를 대상이 없어 **사람도 못 붙인다 — 세션을 새로 여는 길뿐이다.**
  - ⚠ **CLI 에는 재연결·리로드 명령이 없다.** 설정 파일을 만지는 **별개 프로세스**라 이미 떠 있는 세션의 도구 목록에 닿지 않는다.
  - ⚠ **서버를 직접 두드려 우회하지 않는다.** 프로토콜이 HTTP 라 실제로 되기는 하지만 지원되는 경로가 아니고, 이미지 결과는 돌려받아도 볼 수 없다. **되는 것과 그렇게 하는 것은 다르다.**

## 워커는 재연결을 못 누른다 — 브라우저는 워커를 띄우기 전에 떠 있어야 한다

- **Why:** 워커 세션이 시작될 때 브라우저가 꺼져 있었으면 그 워커는 **수명 내내 브라우저를 못 보고 스스로 회복할 수단이 없다.** 붙일 수 있는 것은 사람뿐인데 **워커에게는 사람을 부를 자리가 없다.** 그러면 워커는 **브라우저 검증을 못 한 채 나머지만 보고하고 끝난다** — 보고만 읽으면 그 빠진 자리가 보이지 않는다.
- **How to apply:** 브라우저 검증을 브리프에 넣을 거면 **워커를 띄우기 전에 브라우저가 떠 있는지 확인한다.** 브리프에는 「못 보면 못 봤다고 보고하라」를 함께 적는다.

## 서버가 다시 살아난 뒤에는 세션 이름과 탭이 사라진다 — 새 핸들로 갈아탄다

앱을 껐다 켜면 **서버 쪽 세션 상태가 함께 사라진다** — 붙여 둔 이름이 거기 들어 있고, 브라우저가 탭을 복원하지 않으면 **그 전에 연 탭 자체**도 없어진다.

- **Why:** 옛 핸들로 호출해도 **오류가 나지 않고** 새 세션으로 이어진다. 안내가 함께 오더라도 결과 본문만 보면 성공이라, 붙여 둔 이름이 기본값으로 돌아가 감사 기록이 갈리고 재시작 전에 연 탭을 찾아 헤매게 된다.
- **How to apply:** 회복한 뒤에는 **결과에 실려 온 새 핸들로 갈아타고**, 세션에 이름을 붙이는 호출이 있으면 다시 부른다. 재시작 전에 연 탭은 없다고 보고 필요하면 다시 연다.
