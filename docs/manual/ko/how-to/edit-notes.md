# 노트 편집하기

에디터에서 쓰는 일을 다룹니다: 저장, 링크, 서식, 속성, 템플릿, 오프라인 편집.

Keyring Notes 에서 글을 쓰는 모든 분을 위한 문서입니다.

## 저장

- 입력을 멈추고 1.5초 뒤, 그리고 탭을 바꾸거나 창에서 포커스가 빠질 때 저장합니다. 설정 → **편집기**에서 자동 저장을 끄거나 간격을 바꾸세요.
- `Ctrl/Cmd+S` 는 바로 저장하고 따로 커밋합니다.
- 서버는 같은 사람이 같은 노트를 잇달아 자동 저장하면 10분 동안 한 커밋으로 묶습니다. 사이에 다른 커밋이나 백업이 끼면 새 커밋으로 시작합니다. 에이전트의 쓰기는 묶지 않습니다.

## 다른 곳에서 노트를 고쳤을 때

저장하기 전에 다른 곳(다른 탭, 에이전트, 앱 동기화)에서 노트가 바뀌었으면, 편집을 시작한 버전을 기준으로 양쪽 변경을 합칩니다. 서로 다른 부분이면 자동으로 합쳐 저장합니다.

같은 줄을 다르게 고쳤을 때만 **내 변경을 사본으로 저장**과 **서버 버전 불러오기** 중에서 고르라고 묻습니다. 고를 때까지 자동 저장은 멈춥니다. 오프라인에서 저장한 내용을 다시 연결해 보낼 때도 같습니다.

## Live Preview

Live Preview 는 기본으로 켜져 있습니다. 상태 표시줄이나 설정 → **편집기**에서 끄세요.

- 커서가 없는 줄은 마크다운 기호(`#`, `**`, `~~`, `==`, 백틱, `[글자](주소)`, `[[대상|별칭]]`)를 숨기고 서식만 보입니다.
- 구분선, 인용문, 글머리, 할 일을 그립니다. `---` 는 가로줄, `>` 는 왼쪽 막대, `-`·`*`·`+` 는 점, `- [ ]` 는 체크박스가 됩니다.
- 체크박스를 누르면 할 일을 체크하거나 풉니다. 커서는 있던 자리에 그대로 있습니다. 읽기 전용 노트에서는 누를 수 없습니다.
- 코드 블록은 펜스 줄을 숨기고 언어와 **복사** 단추를 보입니다. **복사**는 안쪽 코드만 복사합니다. 코드는 글 그대로라 그 자리에서 고칩니다. 커서를 블록 안으로 옮기면 펜스가 보입니다.
- 코드는 언어별로 칠하고, 편집 화면과 미리보기가 같은 색을 씁니다. ` ```py `·` ```sh `·` ```yml ` 같은 짧은 이름도 됩니다.
- 임베드, 콜아웃, 수식, Mermaid 다이어그램, 각주, 글 사이의 이미지(`![글](주소)`), HTML 블록은 미리보기와 같이 그립니다. 주석 `%%…%%` 와 블록 ID `^id` 는 숨깁니다.
- 커서를 그 줄로 옮기거나 그린 블록을 누르면 원문이 보입니다. 표는 그린 채로 그 자리에서 고칩니다. [표 편집](#표-편집)을 보세요.
- 맨 앞의 프런트매터는 "속성 N개 — 오른쪽 패널에서 보기 · 원문 보기" 한 줄로 접힙니다. `Ctrl/Cmd+A` 는 본문만 고릅니다. 원문 편집과 미리보기에서도 같습니다. 프런트매터까지 고르려면 먼저 **원문 보기**를 누르세요.

`Ctrl/Cmd+E` 로 편집과 미리보기를 오갑니다. 지원하는 문법은 [참조](../reference.md#마크다운-문법)에 있습니다.

## 표 편집

Live Preview 에서는 커서가 표 안에 있어도 표를 그린 채로 두고, 그 자리에서 고칩니다. 인용문·목록·콜아웃 안의 표는 원문으로 보입니다.

- 셀을 누르면 그 셀을 고칩니다. 고치는 셀은 `**굵게**`·`[[대상|별칭]]` 같은 마크다운 원문으로 보이고, 노트 본문과 같은 `[[` 자동완성과 서식 단축키가 됩니다. 다른 셀은 그린 채로 있습니다.
- 셀에서는 `|` 를 그대로 치면 됩니다(`\|` 도 됩니다). 어느 쪽이든 `\|` 로 저장되고 셀이 나뉘지 않습니다. 셀에는 줄바꿈을 넣을 수 없어서 `Shift+Enter` 는 `<br>` 을 넣고, 여러 줄을 붙여 넣으면 `<br>` 로 잇습니다.
- 셀이 모자란 행의 끝 빈 셀에 치면 그 행에 모자란 셀을 붙입니다.
- 실행 취소와 다시 실행(`Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z`)은 셀과 노트 본문을 한 기록으로 다룹니다.
- 파일에서는 고친 셀과 행만 바뀝니다. `|` 사이의 공백은 그대로 둡니다.

| 키 | 셀에서 |
| --- | --- |
| `Tab` / `Shift+Tab` | 다음 / 이전 셀. 마지막 셀에서 `Tab` 은 행을 넣습니다 |
| `Enter` | 아래 셀. 마지막 행에서는 행을 넣습니다 |
| `←` `→` | 셀 글의 처음이나 끝에서 왼쪽이나 오른쪽 셀 |
| `↑` `↓` | 위나 아래 셀. 첫 행 위나 마지막 행 아래로 가면 표 앞이나 뒤 줄 |
| `Esc` | 셀 편집을 끝내고 표 뒤 줄로 |

표 바로 위나 아래 줄에서 `↓` 나 `↑` 를 누르면 표로 들어갑니다. 위 줄 끝에서 `→` 를 누르면 첫 셀로, 아래 줄 처음에서 `←` 를 누르면 마지막 셀로 들어갑니다. 표 옆 빈 곳을 누르면 그 행의 가장 가까운 셀이 열립니다. 입력기(IME)가 글자를 조합하는 동안 `Tab` 과 `Enter` 는 글자를 확정만 합니다. 한 번 더 누르면 옮깁니다.

행이나 열에 마우스를 올리면 행 왼쪽이나 열 위에 손잡이가 보입니다. 터치 화면에서는 고치는 셀의 손잡이가 늘 보입니다.

- 행 손잡이를 누르면 위나 아래에 행을 넣거나, 행을 위나 아래로 옮기거나, 행을 지웁니다. 머리 행은 아래에 행 넣기만 됩니다.
- 열 손잡이를 누르면 열을 넣거나 옮기거나 지우고, 글 맞춤(**왼쪽 맞춤**·**가운데 맞춤**·**오른쪽 맞춤**·**맞춤 없음**)을 정하고, 그 열의 값으로 행을 오름차순·내림차순 정렬합니다. 행 정렬은 숫자(`1,000`, `2%`)를 숫자로 비교해 글보다 앞에 두고, 빈 셀을 맨 뒤에 둡니다. 파일의 행 순서가 바뀝니다.
- 손잡이를 끌면 행이나 열을 옮깁니다. 놓을 자리에 선이 보입니다. Esc 를 누르면 취소합니다.
- 바꾼 것은 `Ctrl/Cmd+Z` 한 번에 되돌아갑니다.

표 오른쪽 위의 **⋯** 단추에는 **원문으로 편집**이 있습니다. 커서가 표 밖으로 나갈 때까지 그 표를 원문으로 보여 주므로, 모양이 깨진 표를 고칠 수 있습니다.

찾기 막대나 검색 결과가 표 안의 글로 가면 그 셀이 열리고 그 글이 골라집니다. 다른 셀의 일치는 그 셀로 갈 때까지 강조되지 않습니다.

## 링크와 임베드

`[[` 를 치면 노트와 첨부 이름이 자동완성됩니다. 같은 이름이 여럿이면 경로로 구분합니다. 제목에 자기 글로 링크하려면 `[[노트#제목|별칭]]`, 이미지를 300픽셀 폭으로 넣으려면 `![[이미지.png|300]]` 을 쓰세요.

`![[노트]]` 같은 노트 임베드는 문단에 임베드만 있을 때만 그 노트의 내용을 펼칩니다. 자기 자신을 임베드하거나 3단계보다 깊이 겹치면 링크로 보이고, 없거나 볼 수 없는 노트는 끊어진 링크로 보입니다.

## 노트 안에서 찾고 바꾸기

`Ctrl/Cmd+F` 를 누르면 에디터 위에 찾기 막대가 열립니다. 치는 대로 찾고 `3/12` 처럼 일치 수를 보입니다.

- **대소문자 구분**, **단어 단위로**, **정규식 사용**을 켜고 끌 수 있습니다.
- 다음·이전 결과는 Enter·Shift+Enter 또는 `Ctrl/Cmd+G`·`Ctrl/Cmd+Shift+G` 로 갑니다.
- `Ctrl/Cmd+Alt+F` 로 바꾸기 줄을 펼칩니다.
- Esc 를 누르면 막대를 닫고 에디터로 돌아갑니다.

## 내용 접기

제목(다음 같은 수준 이상의 제목까지), 하위 항목이 있는 목록 항목, 콜아웃, 6줄 이상의 코드 블록, 표를 접을 수 있습니다.

- 에디터에서는 줄 왼쪽의 ▸/▾(마우스를 올리면 보임), 미리보기에서는 블록 왼쪽 단추, 개요 패널에서는 제목 옆 단추를 쓰세요. 셋은 같은 상태를 씁니다.
- 명령: 지금 위치 접기·펴기, 모두 접기·펴기, 이 수준 제목만 보기. 단축키는 설정 → **단축키**에서 바꿉니다.
- 접힌 상태는 노트마다 이 기기에 기억합니다. 파일은 바뀌지 않습니다.
- 검색이나 링크로 제목·블록에 가면 접힌 자리를 폅니다.

## 할 일

`- [ ] 할 일` 을 쓰세요. 미리보기의 체크박스를 누르면 원문이 바뀌고, 에디터에서는 `Ctrl/Cmd+Enter` 를 누르세요.

## 속성

오른쪽 패널의 **속성** 탭은 프런트매터 필드를 종류에 맞는 입력칸으로 보입니다: 글, 숫자, 체크, 날짜, 날짜·시간, 목록. 노트 머리의 속성 단추나 접힌 프런트매터 줄로도 엽니다.

- 필드 이름 바꾸기, 종류 바꾸기(값을 옮김), 지우기, 더하기가 됩니다. 이름과 값은 볼트에서 쓰던 것을 권합니다.
- 필드의 **×** 단추로 지우면 먼저 확인을 묻습니다.
- 고친 내용은 초안에 들어가므로 저장해야 반영되고 실행 취소도 됩니다. 다른 필드의 순서, 주석, `[a, b]` 모양은 그대로 둡니다.
- YAML 이 깨져 있으면 원문에서 고치라고 알립니다.

## 템플릿

- **템플릿 넣기**는 지금 워크스페이스 템플릿 폴더의 노트를 커서 자리에 넣습니다.
- **템플릿으로 새 노트**는 제목을 묻고 지금 노드 아래에 새 노트를 만듭니다.

템플릿 변수는 [참조](../reference.md#템플릿-변수)에 있습니다.

## 오프라인 편집

웹 앱은 홈 화면에 앱으로 설치할 수 있습니다. 설치한 앱은 볼트 전체를 기기에 두고 서버와 동기화하므로, 연결이 없어도 모든 노트가 열리고 검색도 됩니다. 처음 실행하면 **설정** → **이 기기·동기화**가 서버 주소가 채워진 채로 열리고, 기기의 볼트가 비어 있고 연결하지 않은 동안은 실행할 때마다 열립니다. 서버 비밀번호를 넣으면 볼트를 내려받습니다. 앱이 노트 주소로 시작했으면 설정을 닫을 때 그 노트를 엽니다. **이 기기의 볼트** 절에는 브라우저가 이 저장소를 보존하는지가 나옵니다. 보존하지 않으면 기기 공간이 부족할 때 브라우저가 아직 동기화하지 않은 변경까지 이 기기의 노트를 지울 수 있습니다.

설치한 앱은 모드를 직접 고르지 않았을 때 이렇게 시작합니다. 아래의 서버 모드로 남기려면 같은 브라우저의 탭에서 `https://<서버>/?local=0` 을 한 번 엽니다. `https://<서버>/?local` 을 열면 브라우저 탭에서도 기기 볼트를 씁니다. 새 창으로 연 노트는 그 창을 연 창과 같은 모드로 열립니다. 서버 모드에서 오프라인으로 저장한 내용이 아직 남아 있으면, 그것을 먼저 보내도록 설치한 앱도 한 번 더 서버 모드로 시작합니다.

서버 모드(브라우저 탭, 또는 `?local=0` 뒤)에서는 한 번 연 노트가 연결이 없어도 열리고, 오프라인에서 저장한 내용은 기기에 두었다가 다시 연결되면 보냅니다. 그 사이 서버에서 바뀐 노트는 덮어쓰지 않고, 내 버전을 오프라인 충돌 사본으로 남깁니다. 검색은 서버가 해야 하므로, 연결이 없으면 검색 패널이 그렇다고 알려 줍니다.

웹 앱을 열어 둔 사이에 서버가 새 버전으로 바뀌면 **새 버전이 있습니다.** 알림이 뜹니다. **새로 고침**을 누르면 새 버전으로 바뀝니다. 저장하지 않은 노트는 먼저 저장하고, 저장하지 못하면 새로 고치지 않습니다. 자동 저장이 꺼져 있으면 새로 고치기 전에 저장할지 묻습니다. 앱은 다시 앞으로 돌아올 때, 마지막 확인 뒤 30분이 지났으면 새 버전을 확인합니다.

수식(KaTeX)과 Mermaid 다이어그램은 노트가 쓸 때만 서버에서 받고, CDN 에서 받지 않습니다. 설치한 웹 앱은 처음 연 뒤 이것들을 뒤에서 받아 두므로 오프라인에서도 그립니다.
