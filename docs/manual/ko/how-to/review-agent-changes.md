# 에이전트 변경 검토하기

고른 폴더에 에이전트가 쓴 것이 승인을 받은 뒤에만 볼트에 들어가게 합니다.

에이전트가 바꾸는 것을 들어가기 전에 보려는 분을 위한 문서입니다.

## 검토할 폴더 고르기

레일의 **검토**(✔)를 누르고 **검토 대상**에 폴더를 적으세요. `/` 는 볼트 전체입니다.

그 뒤로는 **에이전트가** 그 폴더 아래에 쓰는 변경이 바로 들어가지 않고 제안으로 쌓입니다. 사람이 쓰는 것은 늘 바로 들어갑니다.

## 제안 승인하거나 거절하기

1. **검토**를 열고 제안을 고르세요.
2. diff 를 읽으세요.
3. **승인**을 누르면 에이전트 이름으로 커밋되고, 커밋 본문에 승인한 사람이 남습니다. 또는 이유를 적어 거절하세요.

권한과 충돌 검사는 에이전트가 제출할 때 합니다. 그 사이 노트가 바뀌었으면 제안에 바뀌었다고 표시되고, 승인은 충돌로 거부됩니다.

상태 표시줄에 검토를 기다리는 수가 보입니다.

## 에이전트에게 보이는 것

- 쓰기는 `pending` 을 돌려주고, 승인 전까지 볼트는 그대로입니다.
- 에이전트는 MCP `my_proposals` 로 결과와 거절 이유를 읽습니다.
- 에이전트가 노트를 옮겨 검토 대상 경로에 닿으면 링크 고치기도 제안 미리보기에 들어갑니다.
