# 데스크톱·모바일 앱 쓰기

앱을 설치하고, 앱이 노트를 어디에 두는지 설명하고, 서버와 연결해 동기화합니다.

서버가 있든 없든 기기에 노트를 두고 쓰려는 분을 위한 문서입니다.

앱은 **서버 없이도** 동작합니다. 노트는 기기 폴더의 마크다운 파일이고, 편집·검색·태그·백링크·위젯·위키 목차·정리 점검·그래프·변경 이력이 모두 기기 안에서 돕니다. 서버 연결은 선택입니다.

## 설치

- **macOS**: [GitHub Releases](https://github.com/jang2162/keyring-notes/releases/latest)에서 `Keyring-Notes_<버전>_universal.dmg` 를 받아 열고 앱을 응용 프로그램 폴더로 끌어 놓으세요. 서명·공증된 앱이고 Apple silicon 과 Intel 에서 모두 돕니다.
- **Windows, Linux, iOS, Android**: 배포하는 앱이 없습니다. [데스크톱·모바일 앱 빌드하기](build-the-desktop-app.md)를 보고 직접 빌드하세요.

## 노트가 있는 곳

| 플랫폼 | 볼트 위치 | 비고 |
| --- | --- | --- |
| Windows, macOS, Linux | `문서/Keyring Notes` | ⇅ → **다른 폴더 열기**로 Obsidian 볼트 같은 다른 폴더를 열 수 있습니다. 다른 편집기에서 고친 파일은 창으로 돌아올 때 다시 읽습니다 |
| iOS | 앱 문서 폴더("파일" 앱에 보임) | |
| Android | 앱 데이터 폴더 | |
| 브라우저 | 이 브라우저의 IndexedDB. 홈 화면에 설치한 웹 앱은 따로 고르지 않으면 이것을 씁니다. 탭에서는 `https://<서버>/?local` 로 열고 `?local=0` 으로 끕니다 | 페이지를 내준 서버와 동기화합니다. [오프라인 편집](edit-notes.md#오프라인-편집) 참고 |

앱은 자기 메타데이터를 볼트 안 `.keyring-app/` 에 둡니다. 점 폴더라서 서버와 Obsidian 은 무시합니다.

## 뒤에 있는 창 누르기

macOS 에서 다른 앱을 쓰다가 Keyring Notes 창을 누르면 창이 앞으로 오면서 누른 것도 바로 동작합니다. 단추는 그 첫 클릭에 눌리고 입력칸은 그 클릭에 커서를 받습니다. PDF 주석 삭제, 속성 지우기, 설정의 **이 기기 설정 초기화**처럼 한 번에 지우는 단추는 먼저 확인을 묻습니다.

## 창 닫기와 끝내기

저장하지 않은 변경이 있는 창을 닫으면 먼저 물어봅니다. **저장하고 닫기**(기본, `Enter`), **저장하지 않고 닫기**, **취소** 중에서 고르세요. 자동 저장이 켜져 있어도, 어느 방법으로 닫든 묻습니다. 닫기 단추, `Ctrl/Cmd+Shift+W`, **Close Window** 메뉴, `Cmd+Q` 모두 같습니다. **저장하고 닫기**는 모든 노트를 저장한 뒤에만 창을 닫습니다. 저장하지 못한 노트가 있으면 창을 닫지 않고 어느 노트인지 알려 줍니다.

창이 여러 개면 `Cmd+Q` 는 지금 창부터 저장하지 않은 변경이 있는 창마다 묻습니다. 차례가 된 창은 앞으로 나옵니다. 어느 창에서든 취소하면 끝내기를 멈추고, 아직 닫지 않은 창은 그대로 둡니다.

저장하지 않은 변경이 있는 창이 응답하지 않으면, 닫고 몇 초 뒤 앱이 시스템 대화상자로 대신 묻습니다. **취소**나 **저장하지 않고 닫기**를 고르세요.

macOS 에서 Dock 으로 끝내거나 로그아웃·시스템 종료할 때는 아직 묻지 않습니다. 먼저 창을 닫거나 `Cmd+Q` 로 끝내세요.

## 데스크톱 앱 업데이트

앱은 실행하고 몇 초 뒤 GitHub Releases 에 새 버전이 있는지 묻습니다. 새 버전이 있어도 하던 일을 막지 않습니다. 대신 레일 아래의 톱니와 설정의 **정보**에 빨간 점이 찍힙니다. 점은 업데이트를 설치할 때까지 남습니다.

설정 → **정보**에 새 버전이 보입니다. **설치…**를 누르면 바뀐 점을 볼 수 있습니다. **업데이트하고 다시 시작**을 고른 뒤에만 업데이트를 받아 서명을 확인하고 설치한 뒤 다시 시작합니다. 다시 시작하기 전에 `Cmd+Q` 처럼 저장하지 않은 변경이 있는 창마다 묻습니다. 취소하면 다시 시작하지 않습니다. 업데이트는 이미 설치됐으니 다음에 앱을 열 때 적용됩니다.

새 버전이 기다리는 동안 `Cmd+Q` 는 먼저 업데이트를 묻습니다. **설치하고 종료**, **그냥 종료**, **취소** 중에서 고르세요.

- **설치하고 종료**는 업데이트를 받아 설치한 뒤 다시 시작하지 않고 끝냅니다. 다음에 앱을 열면 새 버전으로 열립니다.
- **그냥 종료**는 업데이트하지 않고 끝냅니다.
- 어느 쪽이든 그다음에는 위처럼 저장하지 않은 변경이 있는 창마다 묻습니다. 거기서 취소하면 앱은 열린 채로 남고, 설치한 업데이트는 설치된 채로 남습니다.
- 받거나 설치하다 실패하면 오류를 보여 주고, **그냥 종료**나 **취소**를 다시 고르게 합니다.
- 설정에서 업데이트를 받는 중이면 `Cmd+Q` 는 끝내지 않습니다. 끝난 뒤 다시 종료하세요.

Dock 으로 끝내거나 로그아웃하거나, 마지막 창을 닫기 단추로 닫을 때는 업데이트를 묻지 않습니다.

실행 때 확인을 끄려면 설정 → **정보** → **업데이트 자동 확인**으로 가세요. 끄면 실행 때 아무 요청도 보내지 않으므로 빨간 점도 찍히지 않습니다. 같은 자리의 **업데이트 확인**으로 그때그때 확인하고, 새 버전이 있으면 바로 보여 줍니다.

## 서버와 동기화하기

1. 앱 레일 아래의 동기화 단추를 누르거나 설정 → **이 기기·동기화**를 여세요.
2. 서버 주소, 기기 이름, 서버 비밀번호를 넣으세요.
3. **연결하고 동기화**를 누르세요.

서버는 이 기기용 토큰(`kd_…`)을 발급합니다. 서버의 설정 → **기기**에서 기기마다 연결을 끊을 수 있습니다.

동기화는 앱을 열 때, 저장하고 10초 뒤, 창으로 돌아올 때, 5분마다 돕니다. 모바일은 앱이 열려 있을 때만 돕니다.

### 동기화가 변경을 합치는 방식

- 노트마다 양쪽이 마지막으로 같았던 버전(기준점)과 비교합니다. 한쪽만 바뀌었으면 그쪽을 따릅니다.
- 양쪽이 서로 다른 부분을 고쳤으면 3방향 병합으로 합친 내용을 양쪽에 저장합니다. 이력에 자동 병합으로 남아 되돌릴 수 있습니다.
- 양쪽이 같은 줄(또는 바로 붙은 줄)을 고쳤으면 아무것도 덮어쓰지 않습니다. 원래 경로에는 서버 버전이 남고, 이 기기의 내용은 `<이름> (동기화 충돌 사본 <날짜-시각>).md` 로 양쪽에 남습니다. 노트 안에 충돌 표시를 넣지 않습니다.
- 한쪽이 지우고 다른 쪽이 고쳤으면 고친 쪽을 살립니다.
- 마크다운은 양방향으로 맞춥니다. 첨부는 서버에서 받아 오고, 기기에서 새로 만든 첨부는 올립니다. 기기에서 지운 첨부는 서버가 기준점 그대로일 때만 서버에서도 지우고, 그 사이 서버에서 바뀌었으면 서버 것을 다시 받습니다. 기기에서 이미 있는 첨부를 고친 것은 보내지 않습니다.
- 앱에서 첨부가 든 폴더를 옮기면 다음 동기화에서 새 자리의 첨부를 올리고 서버의 옛 자리에서는 지웁니다.
- 공통 설정 파일(`keyring-settings.md`)은 키 단위로 맞춥니다. 양쪽이 같은 키를 바꿨으면 서버 값을 따르고, 화면 설정이면 이 기기 값을 이 기기에서만 쓸지 묻습니다.
- 위키 index·log 는 각자 만듭니다.
- 앱이 서버에 쓴 커밋의 작성자는 `소유자 (<기기 이름>)` 입니다. 기기 토큰으로는 관리 콘솔을 쓸 수 없습니다.

### 서버가 있어야 하는 기능

원본 수집(웹 페이지·PDF 변환), 의미 검색, 변경 검토, 위젯 플러그인 그리기는 서버에 연결된 웹 앱에서 씁니다. 에이전트(MCP)도 서버에만 붙습니다.
