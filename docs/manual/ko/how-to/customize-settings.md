# 설정 바꾸기

설정 창, 기기를 넘어 따라가는 설정, 언어가 어떻게 동작하는지 설명합니다.

Keyring Notes 의 모양과 동작을 자기에게 맞추려는 모든 분을 위한 문서입니다.

## 설정 열기

레일 아래의 톱니를 누르거나, `Ctrl/Cmd+,` 를 누르거나, `#/:settings/<묶음>` 으로 가세요. 설정은 노트 위에 뜹니다.

| 묶음 | 담는 것 |
| --- | --- |
| **일반** | 테마, 아이콘 보이기, 왼쪽 막대 글자, 초기화 |
| **언어** | 화면 언어, 볼트 언어, 언어팩. 서버에서는 에이전트 언어와 서버 언어도 |
| **편집기** | 자동 저장, Live Preview, 글꼴과 크기, 읽기 폭, 줄 번호, 문서 위에 속성 보기 |
| **파일·링크** | 새 링크 모양, 트리 첨부 표시, 문서 끝 백링크, 데일리 표시 |
| **워크스페이스** | 워크스페이스와 각각의 데일리·템플릿·첨부 폴더 |
| **단축키** | 키보드 단축키(데스크톱과 웹만) |
| **이 기기·동기화** | 동기화(앱만) |
| **정보** | 버전, 앱 업데이트(데스크톱 앱만), 오픈 소스 라이선스 |
| 서버 묶음 | 관리 콘솔(서버만, 소유자만). [서버 관리하기](manage-the-server.md) 참고 |

왼쪽 위 검색칸으로 설정을 찾으세요. 지금 언어로도, 영어로도 찾고, "백업"이나 "토큰" 같은 서버 항목도 찾습니다. 설정은 X, Esc, 배경 누르기, 브라우저의 뒤로 가기로 닫습니다. 입력칸 안에서 누른 첫 Esc 는 칸에서 나오기만 합니다.

## 따라가는 설정

**모든 기기** 표시가 붙은 설정은 볼트의 공통 설정 파일에 저장되어 웹과 앱의 모든 기기가 함께 씁니다: 테마, 화면 언어, 편집기 글꼴과 크기, 줄 번호, Live Preview, 읽기 폭, 자동 저장, 아이콘 보이기, 트리 첨부 표시, 데일리 표시, 정렬, 문서 위 속성, 문서 끝 백링크, 왼쪽 막대 글자, 단축키.

- 항목마다 **이 기기에서만 다르게**를 켜면 그 값은 이 기기에만 남습니다. 그 뒤로는 공통 값을 따라가지 않고, 공통 값은 옆에 흐리게 보입니다.
- 쓰는 값의 순서: 이 기기의 덮어쓰기, 공통 값, 기본값.
- 다른 탭이나 동기화로 바뀐 값은 바로 반영됩니다.

이 기기에만 남는 것: 패널 폭과 열림, 왼쪽 보기와 오른쪽 탭, 접은 절, 열린 탭, 트리 펼침, 마지막 노트, 최근 이모지, 비공식 언어팩.

## 공통 설정 파일

공통 설정은 볼트 맨 위 `keyring-settings.md` 의 프런트매터에 있습니다. 마크다운이라 앱 동기화로 함께 맞춰지고, 서버도 이 파일로 `[[날짜]]` 링크를 해석하고 데일리 노트를 알아봅니다.

- 트리, 빠른 열기, 검색, 그래프, 위젯, 속성 자동완성에 나오지 않고, 워크스페이스로 치지 않습니다. 설정 → **일반**의 **원문 열기**로 엽니다.
- 고칠 때마다 파일을 다시 읽고 바뀐 값 하나만 고쳐 쓰므로, 다른 기기가 고친 값을 덮지 않습니다.
- 에이전트는 권한과 상관없이 이 파일을 읽기만 할 수 있습니다.

파일 형식은 [참조](../reference.md#공통-설정-파일)에 있습니다.

## 언어

공식 언어는 영어(기준)와 한국어입니다.

- **화면 언어**는 기기를 넘어 따라갑니다. 처음에는 시스템이나 브라우저 언어이고, 바꾸면 새로고침 없이 바뀝니다.
- **볼트 언어**는 볼트에 저장되는 글을 정합니다: "제목 없음", 충돌 사본, 기본 폴더 이름, 위키 index·log·`SCHEMA.md`, 데일리 형식의 월·요일 이름, 커밋 메시지. 화면 언어와 따로입니다.
- **에이전트 언어**(서버만)는 MCP 도구 설명과 오류의 언어를 정합니다. 기본은 영어입니다.
- **서버 언어**(서버만)는 서버 오류, 로그, CLI 의 언어를 정합니다. 정하기 전에는 `KEYRING_LANG` 이나 `LANG` 을 씁니다.

### 비공식 언어 더하기

1. 설정 → **언어**에서 공식 언어를 언어팩 JSON(`meta` 와 `messages`)으로 내려받으세요.
2. 값을 번역하세요.
3. **언어팩 불러오기**로 더하세요.

불러올 때 검사 결과를 보입니다: 모르는 키, 빠진 키 수, `{name}` 자리가 다른 메시지, 글이 아닌 값, HTML 처럼 보이는 값. 문제 있는 메시지는 버리고, 빠진 키는 기준 언어로 보입니다. 값은 늘 글자로만 그리고, 언어팩은 1MB 까지입니다.

언어팩은 이 기기에만 둡니다. 빠진 키만 내려받기, 고친 팩 불러오기(합치기), 내보내기, 지우기도 됩니다. 다른 기기가 고른 언어의 팩이 이 기기에 없으면 기준 언어로 보이고 알립니다.

## 단축키

`Ctrl/Cmd+/` 로 단축키 목록을 보고, 설정 → **단축키**에서 바꾸세요. 기본값은 [참조](../reference.md#단축키)에 있습니다.
