# 서버 관리하기

관리 콘솔을 다룹니다: 서버 상태, 에이전트, 기기, 업데이트, 비밀번호, 패스키 로그인.

Keyring Notes 서버의 소유자를 위한 문서입니다.

## 관리 콘솔 열기

관리 콘솔은 설정의 **서버** 묶음이고, 명령 **서버 관리(설정)**으로도 엽니다. 소유자만 쓸 수 있고, 에이전트 토큰은 403 을 받습니다. 로컬 모드(앱, 또는 `?local`)에는 서버 묶음이 없습니다.

| 탭 | 할 수 있는 일 |
| --- | --- |
| **서버 상태** | 버전과 실행 시간, 노트·파일 수와 용량, 커밋 수와 마지막 변경, 디스크 여유, 백업 현황, 에이전트별 마지막 접속을 봅니다. HTTPS 아님, 허용 호스트 없음, 백업 없음, 디스크 부족이면 경고합니다 |
| **에이전트·권한** | 에이전트 만들기(토큰과 MCP 설정 예시를 한 번만 보임), 폴더별 권한 표 고치기, 토큰 재발급, 에이전트 지우기 |
| **기기** | 앱에서 연결한 기기와 마지막 동기화를 보고, 기기 연결을 끊습니다 |
| **백업·복원** | 백업, 내려받기, 올리기, 복원, 자동 백업 설정. [백업과 복원](back-up-and-restore.md) 참고 |
| **자동화** | 웹훅과 정기 작업. [웹훅으로 자동화하기](automate-with-webhooks.md) 참고 |
| **업데이트** | 지금 버전과 최신 버전, 업데이트 방법을 봅니다 |
| **보안** | 비밀번호 바꾸기, 패스키 등록·삭제, 원격 접속 안내 |

토큰이나 웹훅 secret 을 한 번만 보이는 화면, 저장하지 않은 권한 표나 웹훅 입력이 있으면 설정을 닫거나 다른 묶음으로 갈 때 묻습니다.

## 비밀번호 바꾸기

**보안**에서 바꾸세요. 다른 기기의 로그인은 모두 끊깁니다. 터미널에서는 `pnpm keyring passwd`, Docker 에서는 `docker compose exec keyring keyring passwd` 로도 정합니다.

## 패스키로 로그인하기

패스키는 비밀번호 없이 지문, 얼굴 인식, 기기 잠금, 보안 키(WebAuthn)로 로그인합니다.

1. **보안**을 열고 **이 주소로 패스키 등록**을 누르세요.
2. 브라우저의 안내를 따르세요.

그 뒤 로그인 화면에 **패스키로 로그인**이 보입니다. 비밀번호 로그인은 패스키를 잃었을 때의 길로 그대로 남습니다.

- 패스키는 등록한 호스트 이름에 묶입니다. `notes.example.com` 으로 등록한 패스키는 IP 주소나 다른 이름으로 접속하면 쓸 수 없습니다.
- 브라우저는 https 주소와 `localhost` 에서만 패스키를 씁니다.
- 서버는 공개 키만 저장하고, 로그인마다 일회용 도전값(5분 유효)에 대한 서명을 확인합니다. Origin 이 받은 호스트와 다른 요청은 거부합니다. 서명 횟수가 뒤로 가는 경우(복제된 인증기 의심)도 거부합니다. 실패가 이어지면 비밀번호처럼 응답을 늦춥니다.
