# 데일리 노트 쓰기

워크스페이스에 데일리 노트를 설정하고, Keyring Notes 가 데일리 노트를 어떻게 알아보고 이름 짓고 태그하는지 설명합니다.

일기나 날마다의 기록을 남기는 분을 위한 문서입니다.

## 오늘 노트 열기

데일리 노트는 워크스페이스마다 따로입니다. 레일의 달력을 누르거나 `Ctrl/Cmd+Shift+D` 를 누르면 지금 워크스페이스의 오늘 노트가 열립니다. 데일리 노트를 끈 워크스페이스에는 달력 단추가 없습니다.

- 이름이 오늘 날짜로 시작하는 노트가 있으면 그것을 엽니다. 날짜 뒤에 제목이 붙어 있어도 됩니다. 여럿이면 고르게 합니다.
- 없으면 날짜만으로 이름 지은 노트를 만들고 커서를 제목 칸에 둡니다.
- 노트 머리의 ◀ 날짜 ▶ 와 **이전 데일리 노트**·**다음 데일리 노트** 명령은 빠진 날을 건너뜁니다. 어제·내일 노트 명령은 그날 노트를 열거나 만듭니다.

## 폴더와 형식 고르기

설정 → **워크스페이스**에서 워크스페이스마다 정합니다. 모든 기기가 함께 씁니다.

- **데일리 노트 폴더**: 볼트 언어가 한국어면 기본 `데일리 노트`, 영어면 `Daily`.
- **묶음 방식**:

  | 묶음 방식 | 형식 |
  | --- | --- |
  | 묶지 않음 | `YYYY-MM-DD` |
  | 연도별 | `YYYY/YYYY-MM-DD` |
  | 연·월별 | `YYYY/MM/YYYY-MM-DD` |
  | 연·주차별 | `GGGG/[W]WW/YYYY-MM-DD` |
  | 직접 입력 | 원하는 토큰. [참조](../reference.md#데일리-노트-형식-토큰) 참고 |

- **주 시작 요일**: 기본은 월요일(ISO 8601)입니다. 일요일도 고를 수 있지만 ISO 가 아닙니다.

설정 아래에 오늘, 어제, 내일, 연말 경계의 경로를 미리 보입니다. ISO 주차로는 2026-12-31 과 2027-01-01 이 둘 다 `2026/W53` 이고, `2027/W01` 은 2027-01-04 에 시작합니다. 그래서 주차 묶음은 주 기준 연도인 `GGGG` 를 씁니다. 파일 이름에 못 쓰는 글자, 빈 칸, `..`, 점 폴더가 나오는 형식은 저장하지 않습니다.

## 데일리 노트로 치는 조건

Keyring Notes 는 이름과 경로만 봅니다. 다음을 모두 만족하면 데일리 노트입니다.

1. 데일리 폴더 아래에 있고, 폴더 경로가 형식의 폴더 부분과 맞습니다.
2. 이름이 형식의 날짜로 **시작**합니다.
3. 날짜 뒤가 이름 끝이거나 구분 글자(공백, ` - `, `_`, `·`)입니다. 그래서 `2026-10-071.md` 는 아닙니다.
4. 날짜로 다시 만든 경로가 실제 폴더와 맞습니다. 그래서 `2026/W41/` 안의 `2026-10-20` 은 아닙니다.

`데일리 노트/2026-10-07 분기 계획 회의.md` 는 2026-10-07 의 노트입니다.

## 데일리 노트가 보이는 모양

제목 칸은 날짜를 흐린 앞머리로 두고 그 뒤의 제목만 고치게 합니다. 날짜를 누르면 전체 이름을 고칩니다. 날짜를 지우면 데일리 노트가 아니게 된다고 알립니다. 트리, 탭, 빠른 열기는 날짜를 흐리게, 제목을 굵게 보이고, 제목이 없으면 `10월 7일 (수)` 처럼 보입니다(설정에서 바꿈).

## 날짜로 링크하기

`[[2026-10-07]]` 은 그날 데일리 노트를 가리킵니다. 이름이 정확히 같은 노트가 있으면 그것이 먼저입니다. 백링크, 그래프, 정리 점검, 링크 고치기도 같은 규칙을 따릅니다. 에이전트에게는 그 에이전트가 볼 수 있는 노트 안에서만 해석합니다. 데일리 노트를 데일리 폴더 밖으로 옮기면 그 링크를 전체 이름으로 고칩니다.

## 자동 태그

새 데일리 노트의 프런트매터에 태그가 들어갑니다. 예: `tags: [데일리/2026/10/07, 10-07, 2026-W41, 수요일]`. 맨 앞 말과 요일은 볼트 언어를 따릅니다. 템플릿의 다른 태그는 그 뒤에 그대로 둡니다.

| 검색 | 찾는 것 |
| --- | --- |
| `#데일리` | 모든 데일리 노트 |
| `#데일리/2026/10` | 그달(하위 태그 포함) |
| `#10-07` | 해마다 이날 |
| `#2026-W41` | 그 주 |

위젯에서는 `from: "#10-07"`, `from: "#데일리/2026/10"`, `where: tags = 2026-W41` 처럼 씁니다.

이름의 날짜를 바꾸면 있는 자동 태그도 함께 고칩니다. 누가 태그를 이름과 어긋나게 바꾸면 정리 점검이 알립니다.

트리의 데일리 폴더에는 아이콘이 보입니다(기본 📅, 설정 → **워크스페이스**에서 바꿈). 데일리 노트 자체에는 아이콘을 넣지 않습니다.

## 기존 노트를 새 형식으로 옮기기

명령 **기존 데일리 노트를 새 형식으로 옮기기**(설정에도 단추가 있습니다)는 데일리 폴더 안 노트 이름 앞의 날짜(`YYYY-MM-DD`, `YYYY.MM.DD`, `YYYYMMDD` 등)를 읽습니다. 지금 형식의 자리로 옮길 목록을 보이고, 확인하면 한 커밋으로 모두 옮깁니다. 날짜 뒤의 제목은 그대로 두고 링크도 고칩니다. 날짜를 못 읽은 파일은 건너뛰고 목록으로 보입니다.
