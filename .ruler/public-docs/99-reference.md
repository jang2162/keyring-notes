# public-docs 참조 지침

아래 작업을 할 때는 **시작하기 전에** 그 파일을 읽는다. 이 규칙들은 상시 지침에 없다.

| 언제 | 읽을 파일 |
| --- | --- |
| README 를 새로 쓰거나 섹션을 더하거나 고칠 때 | `docs/guideline/public-docs/00-readme.md` |
| README 나 사용자 문서에 스크린샷·GIF·다이어그램을 넣거나 바꿀 때 | `docs/guideline/public-docs/01-images.md` |
| 사용자 문서(docs/manual/)를 만들거나 README 에서 내용을 나눠 옮길 때 | `docs/guideline/public-docs/02-manual.md` |
| 번역 문서를 만들거나, 영어 원본 문서를 고치거나, 문서 언어를 추가할 때 | `docs/guideline/public-docs/03-i18n.md` |
| README 나 사용자 문서의 문장·코드 블록·링크를 쓰거나 번역할 때 | `docs/guideline/public-docs/04-style.md` |
| README 에 후원 섹션을 넣거나 .github/FUNDING.yml 을 만들 때 | `docs/guideline/public-docs/05-support.md` |
| 새 저장소의 README.md 나 README.<lang>.md 를 처음 만들 때 | `docs/guideline/public-docs/06-readme-template.md` |
| 릴리스하거나 저장소를 공개하기 전, README·사용자 문서를 크게 고친 뒤 | `docs/guideline/public-docs/07-release-check.md` |
